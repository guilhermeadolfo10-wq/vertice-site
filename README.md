# Site institucional — Vértice Shipping

Site estático (HTML, CSS e JS, sem build). Domínio: verticeshipping.com.br.

- `index.html` — página principal (serviços, diferenciais, como trabalhamos, sobre, contato).
- `acesso.html` — escolha "Sou Colaborador / Sou Cliente" (também abre como janela pelo botão "Acessar portal").
- `privacidade.html` — Política de Privacidade (LGPD).
- `script.js` — **configuração** no topo: endereços dos portais, e-mail e WhatsApp.

Publicação: qualquer hospedagem estática (Cloudflare Pages, Vercel, Netlify), apontando o domínio no Registro.br.
